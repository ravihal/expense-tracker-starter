# Expense Tracker

> This is the starter project used in my [Claude Code course](https://codewithmosh.com/p/claude-code).

A basic expense tracker app built with React. It intentionally has a bug, poor UI, and messy code — all of which we fix together throughout the course.

## Getting Started

```bash
npm install
npm run dev
```

Then open your browser at `http://localhost:5173`.

## Crypto Prices Script

`index.js` is a standalone Node script that fetches the top 5 cryptocurrencies by market cap from the [CoinGecko API](https://www.coingecko.com/en/api) and prints their name, current price, and 24-hour change in a table.

```bash
node index.js
```
